# Codex TokenBar

为 Windows 版 Codex Desktop 添加逐轮 Token 统计。在每轮最终回复下方保留一条精简统计，点击即可查看本轮详情。

![逐轮统计条](docs/images/tokenbar-inline.png)

## 功能

- **逐轮统计** — 本轮 Token、缓存命中率、截至该轮的对话累计 Token 与累计缓存率。
- **点击查看详情** — 在统计条上方悬浮显示精确输入、输出、平均速度与扣除工具后的时长。再次点击、点击外部或按 Esc 收起。
- **历史快照** — 每条统计对应自己的轮次，后续对话不会改写历史累计值。
- **简洁显示** — Token 使用 k 单位，悬停查看精确数值。详情省略上下文占用。
- **本机运行** — 只读会话用量，通过回环 CDP 连接挂载界面。

## 快速开始

### 准备

需要 Windows 10/11 x64、Microsoft Store 版 Codex，以及 Node.js 22 或更新版本。首次使用可从 Node.js 官网安装 LTS 版本，安装后重新打开 TokenBar。

[下载 Node.js LTS](https://nodejs.org/en/download) · [下载 TokenBar 发布包](https://github.com/JiuGe1024/Codex-TokenBar/releases)

### 安装与启动

1. 在 Releases 中下载名称以 `win-x64.zip` 结尾的发布包，完整解压到一个固定文件夹。
2. 正常退出已经打开的 Codex。
3. 双击 `Codex-TokenBar.exe`，即可启动 Codex 和逐轮统计。

以后从 `Codex-TokenBar.exe` 启动即可。需要任务栏入口时，双击 `创建快捷方式.exe`，将生成的 `outputs\Codex-TokenBar.lnk` 固定到任务栏。移动文件夹后重新创建快捷方式。

启动器会自动检查 Node.js，缺失或版本不兼容时直接提示安装地址。无需先运行环境检查或创建快捷方式。请保留整个解压文件夹。

### 停止与恢复原版

- 停止统计时，双击 `关闭统计.exe`。
- 使用原版入口时，停止统计，取消 TokenBar 的任务栏固定，然后双击 `打开原版.exe`，或重新固定官方 Codex 图标。
- 如需关闭调试端口，请正常退出 Codex，再从官方入口打开。
- 升级时，先关闭统计，将新版完整解压到固定位置，再创建并固定新版快捷方式。

## 统计口径

| 指标 | 含义 |
| --- | --- |
| 本轮 Token | 本轮所有模型调用的输入与输出之和 |
| 输入 Token | 各次调用携带的提示、历史、工具定义及工具结果等输入累计，包含缓存命中部分 |
| 输出 Token | 官方记录的各次模型调用输出累计，包含推理与工具调用参数 |
| 本轮缓存 | 本轮缓存输入 ÷ 本轮输入 |
| 对话累计 | 截至该轮完成时的官方累计快照 |
| 累计缓存 | 累计缓存输入 ÷ 累计输入，按总量加权 |
| 平均速度 | 本轮输出 Token ÷ 扣除工具独占时间后的时长 |
| 时长（扣除工具） | 官方整轮耗时减去已记录的工具独占区间，保留等待和思考 |

一轮对话可能调用模型多次，每次携带的历史都会计入输入。因此输入累计可能显著大于输出，也可能大于单次上下文窗口容量。缓存输入已经包含在输入中，总 Token 使用输入加输出计算。

工具区间按并集合并，重复记录和并行工具只扣除一次，已记录的模型与工具并行部分保留。区间限制在本轮范围内；计时缺失、冲突或出现未知类型时，速度与时长显示 `--`。这是根据客户端生命周期记录估算的扣工具耗时，与 AA 的逐请求端到端计时存在差异。平均速度与时长使用同一时间口径，两者相乘约等于输出 Token，显示值存在四舍五入误差。字段缺失、轮次归属不明确或快照冲突时显示 `--`。

## 数据与连接

- 会话文件位于当前用户的 `~/.codex/sessions`，以只读方式打开。
- 仅投影身份、用量、整轮耗时和生命周期区间字段。JSONL 扫描会经过包含正文的文件字节，非统计内容按结构跳过，正文与凭据不作为产品数据提取或保存。
- CDP 端口固定为 `127.0.0.1:9337`，连接前核验唯一官方主页面与进程所有权。回环监听限制了网络可达范围，但该调试接口没有独立的访问认证，本机可访问端口的程序可能读取页面或执行页面脚本。仅在可信本机环境使用，避免转发或对外暴露此端口；关闭端口需完全退出带调试参数启动的 Codex。
- 无遥测与外部统计服务。页面统计通过 DOM 挂载，用量数据经本机回环连接提供。

## 兼容与当前限制

- 适用于官方 Windows Codex Desktop 的 Codex 对话页面，普通 ChatGPT 页面不挂载。
- 官方原生快捷方式不会替 TokenBar 开启 CDP，日常使用配套入口。
- 页面结构或会话格式变化后，可能需要适配。身份或布局不满足校验时停止挂载。
- 启动脚本持有单实例锁，初次连接最多尝试 3 次。运行中连接中断后，按 1、2、4 秒间隔最多自动重新附加 3 次；本次启动期间累计计算恢复次数。每次都重新核验官方安装、进程与监听，并重新选择唯一官方目标页面。
- Codex 正常退出或用户关闭统计时，启动链退出。安全校验失败、页面执行不兼容时停止；恢复额度耗尽后，使用配套脚本重新附加。
- 分叉继承会话与归档会话尚不支持。旧格式缺少响应身份或计时字段时，相应指标显示 `--`。
- 本机已验证逐轮显示、详情浮层与任务栏分组。完整冷启动、所有 DPI、主题及多屏组合仍需进一步验证。

## 开发与验证

源码开发需要 Node.js 和 npm。Windows 下双击根目录的 `Build.cmd` 可完成依赖安装、测试、启动器构建与 ZIP 打包。产物与 SHA-256 文件位于 `outputs`。

也可单独运行测试。

```powershell
npm ci --ignore-scripts --no-audit --no-fund
npm test
```

当前 41 项自动化测试覆盖数据校验、扣除工具后的速度、有限重连、退出清理、依赖检测、首次创建快捷方式及发布包内容。DOM 测试使用 jsdom，真实窗口布局另行检查。性能与验收边界见 [验证记录](docs/validation.md)。

已准备 Windows、Node.js 22/24 测试与标签发布工作流。当前 GitHub 登录凭据缺少 workflow 权限，工作流暂未上传启用。现可通过 Build.cmd 本地测试并打包 ZIP 与校验和。

本项目 EXE 尚未进行代码签名。下载后可用随包发布的 SHA-256 校验文件核对文件完整性，Windows 也可能显示未知发布者提示。

| 目录 | 内容 |
| --- | --- |
| `src/` | 统计解析、状态模型、CDP 连接、页面组件及启动器源码 |
| `scripts/` | 构建、启动、关闭、诊断与任务栏配置脚本 |
| `tests/` | 自动化测试 |
| `docs/` | 使用说明与展示图片 |
| `outputs/` | 本机构建产物，Git 忽略 |
| `work/` | 本机运行状态与测试产物，Git 忽略 |
