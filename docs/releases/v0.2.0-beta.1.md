# v0.2.0-beta.1

Windows x64 预发布版。发布包需要 Node.js 22+，可从 https://nodejs.org/en/download 安装 LTS 版本。

## 安装

下载 win-x64.zip 并完整解压，正常退出已打开的 Codex，再双击 Codex-TokenBar.exe。需要任务栏入口时，运行创建快捷方式.exe，再固定 outputs/Codex-TokenBar.lnk。启动遇到问题时，可运行环境检查.exe。

关闭统计使用关闭统计.exe；恢复官方入口使用打开原版.exe。完整步骤见 README。

## 本版内容

- 每轮回复下方的 Token、缓存统计及上方详情浮层。
- 按工具独占区间扣除耗时，速度与显示时长采用相同口径。
- 有限安全重连与退出清理。
- 小体积便携包、图形化依赖检查与快捷方式创建。
- 本地自动测试与发布校验和。Windows Node.js 22/24 的 CI 工作流待补齐 GitHub workflow 权限后启用。
