# v0.2.0-beta.1

Windows x64 预发布版。发布包需要 Node.js 22+，可从 https://nodejs.org/en/download 安装 LTS 版本。

## 安装

下载 win-x64.zip 并完整解压，正常退出已打开的 Codex，再双击 Codex-TokenBar.exe。正常退出 Codex 后统计后台自动结束，使用原版时从官方图标打开。

## 本版内容

- 每轮回复下方的 Token、缓存统计及上方详情浮层。
- 按工具独占区间扣除耗时，速度与显示时长采用相同口径。
- 有限安全重连与退出清理。
- 小体积便携包、单 EXE 启动与自动依赖检查。
- 本地自动测试与发布校验和。Windows Node.js 22/24 的 CI 工作流待补齐 GitHub workflow 权限后启用。

## 验收边界

EXE 尚未进行代码签名。官方应用完整冷启动、真实崩溃/更新后的恢复、全部 DPI/多屏组合与多日运行尚待验收。资源采样结果见 docs/validation.md。
