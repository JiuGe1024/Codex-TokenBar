# 第一阶段验证记录

## 单入口发布包

当前发布包只提供 Codex-TokenBar.exe。已移除四个辅助 EXE 的生成逻辑，并排除快捷方式创建与独立环境检查脚本。包内容测试断言根目录只有一个 EXE、没有快捷方式，41 项测试全部通过。正常退出官方客户端后后台自动结束，使用说明已统一。下文涉及辅助入口的记录描述的是此前验证版本。

## 解压后直接启动

主 EXE 的启动链在打开 Codex 前自动检查 Node.js，缺失依赖时直接展示原因与安装地址。环境检查和快捷方式创建均为可选入口。新增回归测试确认缺失依赖时不打开 Codex，并记录可供启动器显示的错误。当前 41 项测试全部通过，已重新构建便携 ZIP。新包首次冷启动的界面验证尚待执行。

## 启动器重复点击修复

2026-11-08，40 项自动化测试通过。启动器已有实例时改为聚焦已验证的官方窗口，聚焦路径有独立互斥锁，未发现窗口时直接结束。隔离测试执行 92 次并发启动，确认统计后台只启动一次，并验证重复点击进入聚焦路径。用户已确认解压包环境检查与首次创建快捷方式成功，用户随后已确认修复后的真实窗口聚焦正常。

现场检查时发现一套 TokenBar 启动链，未复现用户报告的 92 个常驻实例。约 431 秒的资源采样中，单核 CPU 平均 0.247%，工作集 57.84–60.20 MiB，句柄数维持 183。

验证日期为 2026-11-08。环境为 Windows、Node.js 24.20.0，真实客户端为 Microsoft Store Codex Desktop 26.1103.4239.0。

## 性能测量

使用相同文件，在同一 Node 进程内交替执行改动前后的读取器各三次。8 MiB 长行主要包含会被跳过的非统计字符串。

| 项目 | 改动前 | 改动后 |
| --- | --- | --- |
| 8 MiB 长行首次读取中位数 | 167.1 ms | 35.7 ms |
| 上述读取中 Buffer.concat 累计复制量 | 524.0 MiB | 8.0 MiB |

跨块片段改为各自保存一次，在完整行到达后合并一次。完整行直接解码，16 MiB 行上限及超限丢弃行为继续生效。

另外测得以下结果。

- 3,001 个历史文件的唯一会话定位约 15–16 ms，保留现有查找逻辑。
- 1,000 轮、约 8.54 MiB 的模拟会话首次解析约 62.8 ms，无数据警告，累计快照校验一致。
- 对该会话最后十轮执行 500 次快照投影约 3.7 ms，保留现有快照逻辑。

结果受机器、缓存和数据分布影响，用于定位本次改动的具体开销。

## 剩余边界

自动恢复额度为每次启动最多三次，恢复成功后额度继续累计。安全验证失败和兼容性错误停止恢复；官方进程退出和主动停止结束启动链。耗尽额度后可通过正式启动脚本手动附加。

CDP 监听提供本机调试能力，没有独立的访问认证。本机可访问端口的程序可能读取页面或执行页面脚本。保持回环监听，避免端口转发与对外暴露。关闭此调试接口需完全退出带调试参数启动的官方客户端。

## 工具耗时扣除更新

新增两项针对性回归测试，当前共 37 项。时长改为官方整轮耗时减去工具独占区间，工具区间先合并，再保留已记录的模型重叠部分。覆盖重复、并行、跨轮边界裁切、网页搜索扩展、晚到记录、冲突与未知类型。缺少生命周期证据的旧轮次显示 --。速度按同一有效时长计算。

原输出 928 Token 的实测轮次，官方总耗时 54.489 秒，扣除后为 40.004 秒，速度约 23.2 tok/s。该方法基于客户端已记录区间进行估算，尚未获得 AA 所需的逐请求完整计时。
